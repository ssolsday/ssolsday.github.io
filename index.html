01

수집하는 개인정보Information We Collect

본 앱은 사용자의 개인정보를 수집하지 않습니다. 사용자가 입력하는 시간표 데이터(과목명, 수업 시간, 학급 정보 등)는 사용자의 기기 내부에만 저장되며, 외부 서버로 전송되지 않습니다. 사용자가 별도로 Google Drive 동기화를 켠 경우에만 이 데이터가 사용자 본인의 Google 계정 안에도 저장됩니다 (자세한 내용은 3항 참고).

This app does not collect any personal information. Timetable data entered by the user (subject names, class times, class labels, etc.) is stored only on the user's device and is never transmitted to external servers. Only if the user turns on Google Drive sync is that data also stored in the user's own Google account (see Section 3).

02

데이터 저장 방식Data Storage

모든 데이터는 기기 내부 저장소에 저장되며, 인터넷 연결 없이도 앱을 완전히 사용할 수 있습니다. Google Drive 동기화를 켠 경우에는 같은 데이터가 사용자 본인의 Google Drive 계정에도 저장됩니다. 앱을 삭제하면 기기에 저장된 데이터는 함께 삭제되며, Drive에 저장해둔 백업본은 사용자가 Drive에서 직접 삭제하기 전까지 사용자 본인의 계정에 남아있습니다.

All data is stored in local storage on the user's device, and the app works fully offline. If the user enables Google Drive sync, the same data is also stored in the user's own Google Drive account. Deleting the app removes the locally stored data; any backup already saved to Drive remains in the user's own account until the user deletes it there directly.

03

접근 권한Permissions

본 앱은 다음 권한을 요청할 수 있습니다.

This app may request the following permissions.

3.1알림Notifications

목적: (1) 수업 시작 10분 전 알림, (2) 현재/다음 교시를 잠금화면에서도 확인할 수 있도록 상시 표시되는 알림. 두 알림 모두 기기에 저장된 시간표 데이터를 기반으로 기기 내부에서 처리되며 외부 서버로 전송되지 않습니다. 앱 최초 실행 시 요청되고, 거부해도 시간표 확인 등 기본 기능에는 영향이 없습니다(알림 관련 기능만 제한됩니다).

Purpose: (1) a reminder 10 minutes before each class starts, and (2) an ongoing notification showing the current/next class, viewable even on the lock screen. Both are generated locally from the timetable data on the device and never sent to a server. Requested on first launch; denying it does not affect core functionality (only notification features are limited).

3.2정확한 알람 예약Exact alarms

목적: 교시 시작·종료 시각에 맞춰 위젯과 알림을 정확히 갱신하기 위해 사용됩니다. 개인정보 수집과는 무관한 시스템 권한입니다.

Purpose: used to update widgets and notifications precisely at each class's start and end time. A system permission unrelated to data collection.

3.3저장소 (구형 기기 한정)Storage (older devices only)

목적: 시간표를 이미지로 갤러리에 저장하는 기능에 사용됩니다. Android 10 이상에서는 이 권한 없이 시스템 갤러리 저장 기능으로 동작하며, 그보다 오래된 기기에서만 요청됩니다. 이미지 저장 기능을 쓸 때만 요청되고, 거부해도 기본 기능에는 영향이 없습니다.

Purpose: used to save the timetable as an image to the photo gallery. On Android 10+ this works through the system's gallery-saving mechanism without this permission; it is requested only on older devices, and only when the image-export feature is used. Denying it does not affect core functionality.

3.4인터넷Internet

목적: Google Drive 동기화 기능을 사용할 때만 통신이 발생합니다. 이 기능을 쓰지 않으면 앱은 어떤 네트워크 통신도 하지 않습니다.

Purpose: network access occurs only when using Google Drive sync. If this feature is not used, the app makes no network requests at all.

3.5Google Drive 저장 및 동기화 (선택 기능)Google Drive storage & sync (optional)

목적: 사용자가 입력한 시간표 데이터를 여러 기기 간에 동기화하기 위해, 사용자 본인의 Google Drive 계정에 백업합니다.

저장 데이터: 과목명, 수업 시간, 학급 정보 등 사용자가 직접 입력한 시간표 데이터, 그리고 연동된 Google 계정의 이메일 주소(어떤 계정과 연동돼 있는지 화면에 보여주기 위해 기기에만 저장됩니다).

앱은 사용자 본인의 Drive 안에서도 다른 파일과 분리된 앱 전용 숨김 공간(App Data 폴더)에만 접근하며, 이 폴더는 사용자의 Drive 화면에 노출되지 않고 다른 앱도 접근할 수 없습니다. 이 데이터는 제3자와 공유되지 않으며, 동기화를 끄면 이후로는 기기 내부 저장소만 사용됩니다.

Purpose: backs up the user's timetable data to their own Google Drive account so it can sync across devices.

Data stored: subject names, class times, class labels and other timetable data entered by the user, plus the email address of the connected Google account (kept on-device only, to show which account is linked).

The app only accesses a hidden, app-specific space within the user's own Drive (the App Data folder), separate from the user's other files; it is not visible in the user's Drive and cannot be accessed by other apps. This data is never shared with third parties. Turning sync off means only local device storage is used from then on.

Google 사용자 데이터 정책 준수Compliance with Google's User Data Policy

OnTime의 Google Drive 연동 기능은 Google API 서비스 사용자 데이터 정책을 준수하며, 이 정책에 명시된 제한된 사용(Limited Use) 요건을 따릅니다. Google 계정을 통해 얻은 정보는 본 방침에 설명된 시간표 동기화 기능을 제공하는 용도로만 사용됩니다.

OnTime's Google Drive integration complies with the Google API Services User Data Policy, including its Limited Use requirements. Information obtained through the user's Google Account is used only to provide the timetable sync feature described in this policy.
